# Why each rule exists

Read this before relaxing a rule. Numbers come from the cited papers and posts as reported in a November 2026 research pass. Links were opened then.

| Rule in SKILL.md | Evidence |
|---|---|
| Blind A/B labels, random order, swapped audit | GPT-4 was order-consistent on only 65% of close pairs ([Zheng 2023](https://arxiv.org/abs/2306.05685)). |
| Judges never see scores, change logs, or "I fixed X" | Judges inside the refinement context inflated scores while human-rated quality fell. Fresh-context judges tracked humans better ([Jane Pan 2024](https://arxiv.org/abs/2407.04549)). Persuasive additions raised scores of wrong answers by up to 8% ([Hwang 2025](https://arxiv.org/abs/2508.07805)). In Theo's T3 Code UI experiment, a UI rated 9 scored 7.4 when re-judged fresh, and unchanged competitor screenshots drifted into the 9s ([transcript](https://www.usetranscribe.io/yt/xq0eB8vxeqk/agents-ui-improvement)). |
| Cross-family panel | A three-family panel raised agreement with humans from kappa .627 to .763 at about 7x lower cost than GPT-4 alone ([PoLL, Verga 2024](https://arxiv.org/abs/2404.18796)). Models favor their own outputs ([Panickssery 2024](https://arxiv.org/abs/2404.13076)). |
| Verify blockers yourself | In one nine-model review, eight models agreed on a false issue ([Titration thread](https://www.reddit.com/r/claudeskills/comments/1wsf42j/claude_code_iterates_on_my_prompts_until_they/)). A three-family ensemble accepted 55% of errors under optimization pressure ([Zhou 2026](https://arxiv.org/abs/2607.05904)). |
| Judge writes its own bar first | Making the judge commit its own answer before grading cut false positives from .719 to .012 ([Zhou 2026](https://arxiv.org/abs/2607.05904)). Writing the bar is the closest analogue for taste. |
| Binary checks plus anchored scores | Checklists raised agreement between evaluators ([CheckEval](https://arxiv.org/abs/2403.18771), [TICK](https://arxiv.org/abs/2410.03608)). Practitioners prefer pass/fail for clarity ([Husain and Shankar](https://hamel.dev/blog/posts/evals-faq/why-do-you-recommend-binary-passfail-evaluations-instead-of-1-5-ratings-likert-scales.html)). 1-10 tracked humans better than 1-5 or 1-100 on SummEval, and scores bunch near the top ([Stureborg 2024](https://arxiv.org/abs/2405.01724)). |
| "If you can name an improvement, 8 or lower" | Anchor copied from [critic-loop](https://github.com/localhugdealer/critic-loop/blob/main/skills/critic-loop/SKILL.md). It counters scores bunching at 8 to 9. |
| Keep the incumbent, revert regressions | Intrinsic self-correction dropped GPT-4 on GSM8K from 95.5% to 89.0% ([Huang 2023](https://arxiv.org/abs/2310.01798)). One 2026 setup gained 25.5 points while breaking 19.1% of answers that started correct ([Zhang 2026](https://arxiv.org/abs/2609.35832)). In Jetty's pelican runs, self-scores rose 2.2 points while 9 of 15 lineages ended worse by an external judge ([Jetty](https://evaljetty.com/pelicans/investigations/hill-climbing.html)). |
| Score the reference every round, keep on paired gaps | The reference is a built-in control for judge drift (Theo's experiment above). Per-judge paired gaps cancel drift that hits both sides equally. Drift that hits only one side doesn't cancel, which is why the helper also flags reference drift and suspect jumps. This part is an engineering inference. |
| Plateau rule and round cap | Proxy scores keep rising after true quality peaks ([Gao 2022](https://arxiv.org/abs/2210.10760)). Anthropic's hillclimb guide calls a plateau only after 3 or more flat rounds ([eval-hillclimb.md](https://github.com/anthropics/skills/blob/main/skills/claude-api/shared/evals/eval-hillclimb.md)). critic-loop's author reports typical UI gains from 6 to 8 that often stop short of 9. |
| Hard gates before judges | Tool-grounded critique beat critique without tools by a wide margin ([CRITIC](https://arxiv.org/abs/2305.11738)). AlphaEvolve rejects candidates with cheap checks first ([AlphaEvolve](https://arxiv.org/abs/2506.13131)). |
| Several screenshots across states | Judge agreement with humans rose from 79% with code only to 91% with multiple screenshots ([ArtifactsBench](https://arxiv.org/abs/2507.04952)). Visual fidelity and human preference come apart ([Design2Code](https://arxiv.org/abs/2403.03163)). Screenshots don't prove interactions work ([FlowEval](https://arxiv.org/abs/2605.04165)). |
| Frozen, versioned contract | Criteria shift once people see outputs ([Shankar 2024](https://arxiv.org/abs/2404.12272)). autoresearch keeps the evaluator off-limits to the agent ([program.md](https://github.com/karpathy/autoresearch/blob/master/program.md)). |
| Fresh auditor kept out of the loop | Any judge that selects revisions becomes part of the optimization target ([Gao 2022](https://arxiv.org/abs/2210.10760)). Using a separate auditor is an engineering inference, not a tested result. |
| Required checks, and a floor per criterion as well as the mean | An average hides a weak criterion: 10, 10, and 7 average 9. [Rulph](https://github.com/team-attention/hoyeon/blob/main/skills/rulph/SKILL.md) requires overall threshold AND per-criterion floor for this reason. Anthropic's eval guidance pairs executable checks for what must work with model judgment for quality ([demystifying evals](https://www.anthropic.com/research/demystifying-evals-for-ai-agents)). |
| Judges critique the rubric (`rubric_flags`) and need substance for PASS | "A passing grade on a weak assertion is worse than useless" ([Anthropic skill-creator grader](https://github.com/anthropics/skills/blob/main/skills/skill-creator/agents/grader.md)). |
| Confirm close calls head to head, never re-judge to fish | Position bias makes single close comparisons unreliable ([Zheng 2023](https://arxiv.org/abs/2306.05685)). Re-sampling judges until one says yes is selection on noise. |
| No self-evaluation fallback | Rulph falls back to the main agent grading its own work when all judges fail. That's the self-preference this skill exists to avoid, so the skill stops with `VERIFICATION_BLOCKED` instead. |
| Holdout states | Feedback that selects revisions turns the judged screens into training data ([Gao 2022](https://arxiv.org/abs/2210.10760)). States never judged during the loop show whether fixes generalize. |
| Rubric wording matters | "Museum quality" language pushed Anthropic's generated designs toward one look ([Anthropic, harness design](https://www.anthropic.com/research/harness-design-long-running-apps)). |

No study validates a specific target score, panel size, or round count for reaching parity with a reference product. The defaults here are starting points.
